# v0.1 桌面体验版实现记录

日期：2026-11-17。交付目标：响应“先开发一版，我看下”，提供可运行、可保存资料的 macOS 页面体验。**这是 MVP 的体验版子集，尚未完成完整微信回复闭环。**

## 1. 启动

本轮追加更新（旧版正在运行时需退出后重新打开应用包）：

- 设置 → 语气管理：新增命名模板、编辑/删除自定义模板、逐项开关。聊天面板只显示已开启语气，内置选项改为“随口聊聊、温柔一点、有点嘴贫、专业简短”。
- 设置 → 同步设置：默认关闭，间隔默认 30 秒，范围 5～300 秒。窗口隐藏、生成过程中和手动片段时暂停；仅重新载入当前示例源，不调用模型，不清除草稿。
- 主面板的本次背景默认关闭；开启才显示文本框，关闭后生成请求中的 background 为空。
- 聊天记录单独展示；群聊可选一条或多条消息，并指定回复成员或整个群。群聊不显示档案入口、不创建或传入画像。
- 模型 HTTP Client 改为 AppState 中一次创建、应用级复用，继续使用原有超时和取消。不代表每次能复用同一条 TCP 连接，服务端可主动断开；尚未实测网络收益或长时间内存趋势。

本轮新增/修改组件均按功能拆分。验证：12 项前端测试、13 项 Rust 测试通过；构建、ESLint、Rust Clippy 通过；浏览器验证了设置中创建语气、关闭与重载保持、背景开关、群聊无档案、消息/成员选择，以及实际 5 秒示例定时刷新后草稿仍保留。原有私聊档案与数据库迁移保留，不清理用户资料。截图：`output/playwright/group-and-settings.png`。

以下表格保留首版验证记录；上面的增量记录说明本轮实际变化。新版桌面包已重建，但本轮没有强行退出用户正在使用的旧窗口，新增界面本轮以浏览器检查及原生服务单元测试为证据，不能称为新包所有原生交互均已复验。

- 双击项目根目录 `打开回声.command`。
- 或直接打开 `src-tauri/target/debug/bundle/macos/回声.app`。
- 本轮已在当前 Mac 启动该 app，并通过原生界面实际操作。
- 开发预览：项目根目录执行 `npm run dev`，浏览器访问 `http://127.0.0.1:1420`。该地址需要开发服务保持运行。

本机包约 48 MiB，为 arm64 debug 体验包，尚未做对外分发的签名、公证和安装引导。不要求安装 Python/MCP 运行环境，也不要求启动本地 HTTP 后端；浏览器态 Vite 仅用于开发预览。

## 2. 已实现的范围

| 能力 | 实际行为 |
| --- | --- |
| 桌面工程 | Tauri 2.12.5、Vue 3.5.45、TypeScript、Pinia；根 npm workspace 与锁文件 |
| 快捷浮窗 | 原生主窗口、可拖动标题栏、隐藏/最小化、置顶入口、档案展开/收起、托盘入口；注册 Option + Space |
| 示例会话 | 朋友、同事、客户三组虚构场景；显式选对象；展开查看示例聊天 |
| 回复界面 | 三类任务、四种语气、自定义语气、本次背景、参考档案开关、三条候选、编辑和原生剪贴板复制 |
| 演示候选 | 仅预设场景逻辑，明确标注“演示候选”；任意手动片段不能套用固定文案冒充理解 |
| 手动上下文 | 标明我/对方；暂存内存；导入时默认关闭示例档案参考；真实生成需要配置模型 |
| 沟通档案 | 五类资料增删改、锁定、近期项期限、来源展开、联系人隔离 |
| 核对流程 | 示例观察确认/忽略；示例冲突可保留、采纳替换、加入有期限的近期偏好 |
| 更新演示 | “演示一次更新”模拟一条有来源的偏好；明确是示例，非真实 AI 提取 |
| 清理与排除 | 资料与关联正文历史/证据清理；不再记录具体主题；解除排除 |
| 桌面持久化 | 应用自有 SQLite，初始迁移 13 张表；只保存档案和必要摘录，不保存聊天窗口、背景、候选和草稿 |
| 浏览器持久化 | 独立 localStorage 示例档案，仅保存 profiles，不保存会话正文或模型 Key |
| 模型配置/调用代码 | HTTPS 地址、模型名、Keychain 保存/删除、处理范围确认、无聊天连通测试、可取消 HTTP 调用和结构化三候选校验 |

模型配置/调用代码通过静态及规则检查，**没有配置用户服务商和 Key，未完成真实云端联调**。不能据此宣称“模型已接通”或“回复质量已验证”。已有 Key 不会从原生读回前端，新输入的 Key 仅在设置组件短暂存在。

## 3. 实际结构

```text
frontend/src/
  components/WindowChrome.vue
  features/reply/              对象、上下文、语气、候选与主面板
  features/profile/            档案、编辑、提议核对和历史
  features/settings/           模型与连接说明
  domain/                      浏览器体验版规则和固定候选
  bridge/                      原生/浏览器能力边界
  stores/                      回复会话与展示状态
  styles/                      平台色彩和样式
frontend/tests/               规则与异步会话隔离测试
shared/demo-workspace.json    前后端共用的虚构内容
src-tauri/src/
  commands/                    业务命令入口
  application/                 档案事务和提示词/结果处理
  domain/                      DTO、输入约束和虚构数据入口
  infrastructure/              SQLite、模型、窗口/快捷键/托盘
src-tauri/migrations/         自有数据库初始迁移
```

公开源码仅包含桌面体验版；本机历史脚本、工具、报告及运行数据不包含在仓库中。

## 5. 明确未完成

1. **真实微信接入**：ChatSource、固定账号映射、分页/增量读取、媒体缓存副作用控制尚未实现。本版不调用 GreenBubbles 读取真实消息；历史样本验证不随仓库发布，公开范围见 [VALIDATION.md](VALIDATION.md)。
2. **真实模型联调**：未配置用户服务商与 Key；未测真实兼容性、费用、延迟和中文回复质量。Keychain 接口已实现但未用真实凭据完成存取验收。
3. **AI 自动画像**：自动提取、引文核验、成功检查点和阈值调度尚未实现；开关禁用并显示“接入真实聊天后启用”。当前观察与更新均为显式示例。
4. **原生能力完整验收**：快捷键显隐/冲突、置顶、多屏/全屏、窗口位置恢复和托盘各种入口还需完整验收；不能把已注册代码当作这些场景均已通过。
5. **MVP 完整存储机制**：运行元数据、保留期清理、正式迁移校验和/升级流程等尚未完成。v0.1 迁移记录当前使用版本标记，不能宣称已有完整的迁移完整性校验。
6. **完整接口与标准 E2E 脚本**：架构文档的完整异步事件协议仍为目标；v0.1 使用精简命令和可取消 Promise。`npm run test:e2e` 尚未提供，本轮以 Playwright CLI 执行浏览器检查。

本版没有发送微信消息、获取新凭据、改签微信、调整 SIP、恢复旁白或读取其他联系人的真实聊天。

## 6. 后续推进顺序

先根据页面体验反馈调整浮窗与档案入口，然后完成 M0 的数据契约/新增消息/媒体副作用验证；接入真实只读会话并选择一个模型实测，再推进自动档案提取和核对规则。PRD 中的完整 MVP 验收标准保持有效，不因为交付预览而全部勾选完成。
