日期：2026-11-17。版本：0.1.0。范围为 macOS 桌面体验版源码，不是完整 MVP 验收。

新增的启动测试仅使用随机临时目录，验证共享 HTTP 客户端可随应用状态初始化、无模型凭据也可启动、配置重开后保留及数据库权限。它不发网络请求、不访问用户应用数据库或 Keychain。

依赖审计使用 npm 官方 advisory 接口：运行时依赖报告为 0 项；包含开发工具时报告 7 项 moderate，均由 typescript-eslint 的 minimatch 传递依赖引起，没有 high/critical。现有依赖要求 minimatch 10，修复版本为 11；未用强制跨主版本 override 改写上游约束，此项作为开发工具依赖的已知限制保留。扫描结果只说明当时 advisory 数据库的报告范围。

## 页面与原生交互

浏览器使用独立的 Playwright CLI 会话和虚构样本。已检查设置新增语气、启停后主面板可见性、重载持久化、本次背景默认关闭与展开/隐藏、独立聊天记录、群聊选消息和回复对象、群聊无画像、实际 5 秒示例自动刷新及刷新保留草稿。

既有本机原生交互已验证示例生成、编辑、复制反馈、补充档案及退出重开后保留。最新增量主要通过浏览器交互和 Rust 测试验证，没有将用户运行中的应用强制退出；不宣称新包的所有原生能力已复验。

## 隐私与发布范围

公开文件仅包含桌面源码、工具链锁文件、图标、虚构样本与整理后的文档。模型 API Key、本机模型配置、应用数据库、微信凭据、真实聊天、历史采集脚本、探测报告、日志与编译包不纳入 Git。发布前检查待提交文件清单与内容，并对公开快照及 Git 历史执行密钥扫描。

原始历史读取报告留在本机，不包含在公开仓库。历史样本曾核对只读数据库消息的内容、顺序与收发方向，但没有接入本版应用；该样本不能证明真实增量读取、群聊接入或广泛版本兼容。
